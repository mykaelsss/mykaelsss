## 🚀 Featured Projects

### 🏎️ [Formalytx - F1 Telemetry Explorer](https://formalytx.com/)
> **Next.js 16 · React 19 · TypeScript · FastAPI · Cloudflare R2 · Vercel · Railway** - [Repo](https://github.com/mykaelsss/formalytx)

- Replaced on-demand FastF1 loads with a per-lap **Cloudflare R2 archive** (961 sessions, 538k laps, 5.3 GB), cutting real-user p95 latency on uncached requests from **11.8s to 0.68s** and eliminating gateway timeouts
- Traced 30-second API stalls to idle R2 connections dropped in transit; fixed with TCP keepalive on the boto3 pool, cutting p99 latency from **31s to 0.86s**
- A Railway cron job exports each session to R2 **within 15 minutes** of it ending, then re-checks for 2 days to catch steward penalties, writing only changed objects
- Sole developer across 9 typed REST endpoints, serving **~120 unique visitors a month**

### 🦯 [Buddy Walk - Assistive Navigation Research](https://github.com/Buddy-Walk/buddy-walk)
> **TypeScript · Node.js · Express · MongoDB · OpenAI API · Google Street View · Docker** - CSTEP Research Scholar, BMCC

- Built a **trial-evaluation dashboard** showing GPS accuracy, resolved destination, Street View panorama, and outcome for every field test, with filters to compare localization methods side by side
- Implemented a **retry workflow** that reruns past trials through the OpenAI and Street View pipeline with 3-way concurrency, UUIDv7 idempotency keys, lease renewal, and an admin-token gate
- Retries are excluded from the evaluation sample, so reruns never skew the results the team is measuring
